 🧠 Propuesta Estructurada: "MindPulse: Desafío Numérico"   🕹️ 1. Dinámica Base del Juego  El juego consiste en retener y reproducir secuencias numéricas que aparecen en la pantalla durante un tiempo limitado. A medida que el usuario acierta, la dificultad (longitud de la serie y velocidad) aumenta de forma adaptativa.
